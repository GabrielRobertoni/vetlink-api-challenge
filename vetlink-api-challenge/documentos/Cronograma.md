# 📌 Considerações Finais

O projeto foi desenvolvido utilizando conceitos de Programação Orientada a Objetos (POO), arquitetura RESTful e persistência de dados com Oracle Database. Foram implementadas funcionalidades completas de CRUD, paginação, ordenação, validações, tratamento de exceções e documentação da API utilizando Swagger/OpenAPI.
